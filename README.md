# The Artisan's Market

This is a simple e-commerce website for an online marketplace for arts and crafts. The website is built using HTML, Tailwind CSS, and vanilla JavaScript.

## Features

*   **Homepage:** Displays featured categories and trending products.
*   **Product Detail Page:** Shows detailed information about a product, including images, description, price, and customization options.
*   **Seller Page:** Allows artisans to apply to become a seller on the marketplace.
*   **Profile Page:** Includes separate sections for buyers and sellers.
    *   **Buyer Profile:** Shows order history and a wishlist.
    *   **Seller Profile:** Shows the seller's products and payment history.
*   **Raw Materials Page:** A wholesale marketplace for sellers to purchase raw materials.
*   **Wishlist:** Allows users to save products they are interested in.
*   **Toast Notifications:** Provides feedback to the user when an item is added to the cart.

## How to Use

1.  Clone the repository.
2.  Open the `index.html` file in your web browser.

## File Structure

*   `index.html`: The main HTML file.
*   `style.css`: Contains the custom CSS for the website.
*   `data.js`: Contains the mock data for the products, orders, payments, and raw materials.
*   `script.js`: Contains the JavaScript code for the website's functionality.
